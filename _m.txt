fix(vtabs): 便签列表态切到标签模式时左侧栏压住顶栏（左上角成一坨）

用户截图：顶栏左侧变成一团 —— 侧栏的一小截叠在 ☰ 上。
实测根因（两个叠加）：
1. syncVtabsBounds() 无条件写 CSS 变量。**便签列表态下 .card 与 #mainToolbar 都是
   display:none**，getBoundingClientRect() 全返回 0，于是写出
   `--vtabs-top: 0px`、`--vtabs-bottom: 1000px`（1000 = 视口高 - 工具栏 top=0）。
2. 切换视图模式时**没人重量**这两个变量（原来只在 init 和「标签栏位置」下拉变化时量），
   于是那组垃圾值一路沿用。

修：
- syncVtabsBounds()：**只在量到有效值（top > 0）时才写**，量不到就保留上一次有效值，
  让 CSS 兜底值（64/80、50/74）生效 —— 不再写出 0px / 视口高这种垃圾。
- applyViewMode() 末尾调用 applyTabPos()（幂等：重打 body.vtabs/btabs + 重测边界 +
  归零滚动 + 重新定位「+」），覆盖 init 与胶囊切换两条路径。

实测：切换后 vTop=64px / vBottom=80px，侧栏 y=64 = 纸面顶 = header 底（此前 y=0、h=46）。
路径逐个验过：便签列表→标签、标签内切文档、标签→便签、便签编辑态→标签，侧栏都与纸面顶对齐。

回归：_verify_vt2 新增 I 组 7 条（列表态不写坏变量 / 切换后已重量 / 侧栏顶在 header 之下 /
     与纸面顶对齐 ≤1px / 高度不塌 / 编辑态切回也对齐）→ 42 项。13 套全绿。
